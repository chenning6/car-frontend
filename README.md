# 车辆交易网站 - 用户端

## 项目路径
E:\hwcode\car-frontend

## 技术栈
- Vue 3 + TypeScript + Vite
- Element Plus
- Vue Router
- Pinia
- Axios
- vue-i18n (多语言)

## 页面结构
/                   - 首页（车辆列表）
/login              - 登录
/register           - 注册
/post/:id           - 车辆详情
/post/create        - 发布车辆
/profile            - 个人中心
/admin              - 管理后台入口（跳转）

## 功能
- [x] 用户注册登录
- [x] 车辆列表展示（新车/二手车）
- [x] 车辆筛选搜索
- [x] 车辆详情
- [x] 发布车辆
- [x] 评论功能
- [x] 联系车主
- [x] 中文/英文/蒙古文切换
- [x] 管理员审核

## 运行
npm install
npm run dev
